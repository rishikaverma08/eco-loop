# 🌱 EcoLoop — Smart E-Waste Collection and Recycling Gamification Network

**EcoLoop** is a Design Thinking project that encourages people to dispose of electronic waste responsibly through a simple digital deposit system and a gamified reward experience.

🌐 **Live Website:** https://rishikaverma08.github.io/eco-loop/

📦 **GitHub Repository:** https://github.com/rishikaverma08/eco-loop

## 📌 Problem Statement

Electronic waste (e-waste), including old mobile phones, chargers, batteries, and electronic accessories, can harm the environment when it is not disposed of properly.

Many people are unaware of appropriate e-waste disposal methods or lack motivation to recycle their unused electronics.

EcoLoop aims to make responsible e-waste disposal easier, more engaging, and rewarding.

## 💡 Proposed Solution

EcoLoop is a web-based prototype that allows users to record e-waste deposits, earn points, view their deposit history, and explore a reward-based recycling experience.

The project uses gamification to encourage environmentally responsible habits and raise awareness about e-waste management.

## ✨ Features

- **Home Page:** Introduces the EcoLoop concept and its purpose.
- **E-Waste Deposit:** Record electronic waste using a deposit form.
- **Gamified Points:** Earn estimated points for recorded deposits.
- **Rewards Section:** Explore the reward experience associated with recycling.
- **Deposit Tracking:** View previously recorded deposit entries.
- **QR Code:** Generate a QR code linked to the deposit page and a sample collection-bin ID.
- **Local Data Storage:** Save demo records in the browser using localStorage.
- **Responsive Interface:** A clean, green-themed interface designed for easy navigation.
- **Online Deployment:** Published using GitHub Pages.

## 🔄 How It Works

1. Open the EcoLoop website.
2. Navigate to the Deposit section.
3. Select an e-waste item and enter the quantity.
4. Record the deposit and view the estimated points.
5. Visit the Tracking section to review deposit records.
6. Explore the Rewards section to understand the gamification concept.

## 🧠 Design Thinking Approach

The project follows the five stages of Design Thinking:

1. **Empathize:** Understand the challenges people face when disposing of electronic waste.
2. **Define:** Identify the need for a simple and motivating e-waste disposal experience.
3. **Ideate:** Explore solutions such as digital deposits, QR codes, points, and rewards.
4. **Prototype:** Build a web application demonstrating the proposed solution.
5. **Test:** Check the prototype's usability, navigation, deposit flow, and tracking features, and gather feedback for improvement.

## 🚀 Run the Project Locally

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rishikaverma08/eco-loop.git
   ```

2. Open the project directory:

   ```bash
   cd eco-loop
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Build for Production

Run:

```bash
npm run build
```

Vite generates the production files in the `dist` directory.

## ⚠️ Current Limitations

This project is an educational prototype and demonstration of the proposed solution.

- Deposit records are stored locally in the user's browser.
- Points are estimates used to demonstrate gamification.
- The collection-bin ID and QR code demonstrate a proposed workflow; they are not connected to a physical smart bin.
- Real recycler integration, sensor-based bin monitoring, user accounts, and a shared cloud database are not implemented.
- Rewards are illustrative and are not automatically redeemed for real products or services.
